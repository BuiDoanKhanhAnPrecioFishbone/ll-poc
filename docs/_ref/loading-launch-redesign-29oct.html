Rules

  • Launches straight up. The planet sinks and streaks fall past, so the climb reads as progress.
  • Driven by the five real start-up steps. The animation never holds the user back.
  • Shown only if loading takes longer than 0.4 s. Exit takes 0.4 s, then the workspace opens.
  • Text: one line, “Launching your mission…”. It changes only when slow (“Still climbing…” after 5 s) or done (“Welcome aboard”).
  • Error: the rocket is back on the pad, tilted, cracked, one fin off, smoking. Text says what to do: reload first, and if it still fails, send a support ticket. The ticket gets the error ID, screen, time and browser added automatically. Back to Home lets the user carry on elsewhere.
  • Under development: the rocket stands whole on the pad while a robot arm welds it, next to a design doc whose checklist ticks off. Nothing is broken, so there’s no Reload.
  • Reduce Motion: no travel, flicker, streaks or moving smoke. The step bar still updates.
