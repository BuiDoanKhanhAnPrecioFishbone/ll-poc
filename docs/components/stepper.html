Stepper

Status: stable · src/ui/Stepper.tsx · one call site, and it is the product's only wizard. The flow around it is Wizard; this is the control. Written to the template set by button.md.

When to use

To show where someone is in a job with a real order, and to let them go back to a step they have already done.

When not to use

Instead of a stepperUseWhy
Sections of one recordTabsTabs say these are peers; a stepper says this comes first
Progress of a running jobA Loader with a labelA stepper is navigation, not a progress bar
Two stepsTwo screens, or oneA stepper over two steps is a label

Steps are buttons

Not decoration.

Someone who realises on step 3 that they mis-mapped a column on step 1 should go straight back to it, not press Back twice and lose their place.

Forward movement is bounded by furthest — the highest step reached so far. Free movement across work already done; no skipping ahead into a step whose inputs do not exist.

A stepper that lets you land on Summary before a BoM is uploaded is offering a dead end.

numbered={false} is not cosmetic

Run Quotation's labels already carry their numbers — "1 - Config BoM". With the dot numbering on as well, every step reads "① 1 - …", which looks like a rendering fault rather than a design.

showText={false}, for a dialog that already says it

The Run Quotation dialog prints the current step's sentence in its subtitle.

The same words twice, 20px apart, cost 50px of a surface whose content did not fit.

The sentence survives as the control's tooltip, so nothing is lost — it is just no longer said twice at once.

Responsive

WidthWhat changes
≤ 840pxStep descriptions go — four labelled steps need ~760px, and a truncated "1 - Confi…" is worse than no description
≤ 700pxOnly the current step keeps its label; the rest become their marker, still positioned and still clickable

Accessibility

StatusEach step states its own status, so where am I and what is left does not depend on seeing the ticks
UnreachableDisabled, not hidden — the shape of the job stays visible
KeyboardEach step is a real button in document order
